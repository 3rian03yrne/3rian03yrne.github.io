# 3rian03yrne.github.io

Redirect stub. The site lives at https://brianobyrne.com (hosted on Cloudflare).

GitHub Pages has `brianobyrne.com` set as this repo's custom domain, which makes GitHub
301-redirect `3rian03yrne.github.io/*` to `brianobyrne.com/*`. The HTML files are a
fallback in case that redirect ever stops applying. Do not point DNS for brianobyrne.com
at GitHub.
