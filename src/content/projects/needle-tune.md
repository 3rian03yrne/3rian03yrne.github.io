Needle Tune uses your device's microphone to detect pitch in real time, displaying it on a classic needle-style dial. The needle glows from red to green as it sweeps across the dial, always visible at a glance.

It is built around the four strings of a tenor guitar, and it stays out of the way while you work: one dial, one note name, one button.

## Features

- Needle-style analog dial with a glowing indicator, red through green as you close on the note
- Real-time pitch detection off the microphone, optimized for tenor guitar
- Current note name and octave beside the dial, so you know which string you are on
- Reference Tone button for tuning by ear against a tuning-fork tone
- Sharp / flat toggle, so a note reads the way you write it
